# 此專案為課程Deep Learning的作業，作業內容以assignment.md為主

## 以下為此專案執行方法:
* 請將全部檔案放進相同資料夾底下以方便執行
* 將mini-ImageNet資料集放入你所設定的資料夾底下，資料集網址為:https://cchsu.info/files/images.zip
* 若有將所有檔案(包括資料集)放入同資料夾下的話，檔案皆可直接執行(應該吧)
* task_a.ipynb為作業Task A的執行程式，結果會存在checkpoints以及channel_results資料夾下
* task_a_ablation.ipynb為作業Task A的消融實驗，一樣結果會存在checkpoints底下
* task_b_resnet34.ipynb以及task_b_wide.ipynb為作業Task B的基礎以及比較模型，結果會存放到Taskb_checkpoints資料夾下
* task_b_eval.ipynb為計算Task b模型在不同資料的表現以及消融實驗的執行檔，結果一樣存放在Taskb_checkpoints資料夾下
